Если "подвисла" программа или сам графический интерфейс (GUI), то на Windows, Linux и macOS есть разные сочетания клавиш для аварийного завершения процессов или вызова "системного диспетчера":

🪟 Windows

Alt + F4 → закрыть текущее активное окно (если программа реагирует).

Ctrl + Shift + Esc → сразу открыть Диспетчер задач.

Ctrl + Alt + Del → экран выбора действий ("Диспетчер задач", "Сменить пользователя", "Выход").

Win + Ctrl + Shift + B → перезапуск драйвера видеокарты (полезно при зависании графики).

🐧 Linux (X11/Wayland, зависит от окружения)

Ctrl + Alt + Backspace → перезапуск X-сервера (если включено в настройках, иногда отключено по умолчанию).

Ctrl + Alt + F1…F6 → переключение на текстовую консоль (tty), где можно убить процесс через htop или kill.

Ctrl + Alt + F7 / F1 → возвращение в графический интерфейс (зависит от дистрибутива).

Alt + SysRq (PrintScreen) + комбинация → т.н. Magic SysRq Keys (включается в ядре Linux):

Alt + SysRq + R → вернуть контроль над клавиатурой.

Alt + SysRq + E → завершить все процессы, кроме init.

Alt + SysRq + I → убить все процессы.

Alt + SysRq + S → синхронизировать диски.

Alt + SysRq + U → перемонтировать диски только для чтения.

Alt + SysRq + B → немедленно перезагрузить.

🍏 macOS

Command (⌘) + Option (⌥) + Esc → окно "Принудительное завершение программ".

Command (⌘) + Option (⌥) + Shift + Esc (удерживать 3 сек) → сразу завершить текущее активное приложение.

Command (⌘) + Control (^) + Power / Touch ID → принудительная перезагрузка Mac.

Command (⌘) + Option (⌥) + Control (^) + Power → завершение работы.

👉 Если зависает только программа → лучше пользоваться Alt+F4 (Windows), xkill (Linux, по хоткею) или ⌘+⌥+Esc (macOS).
👉 Если зависает вся система → уже спасают "жёсткие" комбинации (Ctrl+Alt+Del, SysRq, Cmd+Ctrl+Power).
